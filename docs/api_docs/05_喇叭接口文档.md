# 喇叭接口文档

> **适用平台**: OSAIG 开源 AI 眼镜 (RV1106B)
> **音频子系统**: ALSA / Rockchip MPI (AO 模块)
> **声卡设备**: `hw:0,0`

---

## 1. 概述

眼镜端通过板载喇叭进行音频输出，支持 PCM 文件播放和 TTS 文本转语音。项目提供了三种使用喇叭的方式：

1. **SDK 客户端 API**（推荐）：通过 `ai_audio.h` 对接 `ai-core` 服务
2. **Rockchip MPI AO 模块**：直接使用 ADEC→AO 管线
3. **ALSA 直接播放**：通过 `snd_pcm_writei` 或 `rk_mpi_ao_test` 工具

**关键文件：**

| 文件 | 作用 |
|------|------|
| `SDK/ai_glass_sdk/include/ai_audio.h` | 音频客户端 API 头文件 |
| `SDK/ai_glass_sdk/docs/Audio_Client_API.md` | API 文档 |
| `SDK/ai_glass_sdk/examples/audio_play_example/` | SDK 播放示例 |
| `samples/audio_streaming/audio_server.c` | ALSA 播放示例 |
| `samples/live_broadcast/simple_adec_bind_ao.c` | MPI ADEC→AO 示例 |

## 2. 方式一：SDK 客户端 API（推荐）

### 2.1 架构

```
┌──────────────┐    Unix Socket          ┌──────────────┐    ALSA/MPI    ┌─────────┐
│   应用程序    │ ──────────────────────► │   ai-core    │ ─────────────► │  喇叭   │
│              │  /tmp/ai-core_audio_ctrl │   服务端      │                │ (SPK)   │
└──────────────┘                         └──────────────┘                └─────────┘
```

- **连接模式**：短连接，每次命令建立新连接
- **播放模式**：排队播放 / 强制打断播放

### 2.2 API 一览

| 函数 | 描述 |
|------|------|
| `ai_audio_init(socket_path)` | 初始化客户端（NULL 使用默认路径） |
| `ai_audio_play(client, &params)` | 播放 PCM 文件（带参数） |
| `ai_audio_play_simple(client, path)` | 简化播放（默认参数） |
| `ai_audio_stop(client)` | 停止播放并清空队列 |
| `ai_audio_cleanup(client)` | 清理客户端资源 |
| `ai_audio_play_tts(client, &params)` | TTS 文本转语音播放 |
| `ai_audio_play_tts_simple(client, text)` | 简化 TTS 播放 |
| `ai_audio_create_default_params(path)` | 创建默认播放参数 |
| `ai_audio_create_default_tts_params(text)` | 创建默认 TTS 参数 |
| `ai_audio_get_error_string(code)` | 错误码转字符串 |

### 2.3 数据结构

```c
// PCM 播放参数
typedef struct {
    const char *file_path;    // PCM 文件路径（必填）
    int volume;               // 音量 (0-100)，-1 使用默认值
    int force;                // 0=排队播放, 1=打断当前播放
    int sample_rate;          // 采样率 (8000-96000)，-1 使用默认值
    int channels;             // 声道数 (1-8)，-1 使用默认值
    int bit_width;            // 位宽 (8/16/24/32)，-1 使用默认值
} ai_audio_params_t;

// TTS 播放参数
typedef struct {
    const char *text;         // 待播报文本（必填）
    int volume;               // 音量 (0-100)，-1 使用默认值
    int force;                // 0=排队播放, 1=打断当前播放
    int use_cache;            // 0=不缓存, 1=使用缓存（推荐）
} ai_audio_tts_params_t;
```

### 2.4 错误码

| 错误码 | 值 | 说明 |
|--------|-----|------|
| `AI_AUDIO_SUCCESS` | 0 | 成功 |
| `AI_AUDIO_ERROR_INIT` | -1 | 初始化失败 |
| `AI_AUDIO_ERROR_CONNECT` | -2 | 连接失败 |
| `AI_AUDIO_ERROR_SEND` | -3 | 发送失败 |
| `AI_AUDIO_ERROR_PARAM` | -4 | 参数错误 |
| `AI_AUDIO_ERROR_RESPONSE` | -5 | 服务端响应错误 |

### 2.5 播放示例

#### 基本播放

```c
#include "ai_audio.h"

int main() {
    ai_audio_t *client = ai_audio_init(NULL);  // 使用默认 socket 路径
    if (!client) return -1;

    // 简单播放
    ai_audio_play_simple(client, "/oem/usr/bin/resources/beep.pcm");

    ai_audio_cleanup(client);
    return 0;
}
```

#### 带参数播放

```c
#include "ai_audio.h"

int main() {
    ai_audio_t *client = ai_audio_init(NULL);

    ai_audio_params_t params = {
        .file_path = "/data/alert.pcm",
        .volume = 80,              // 音量 80%
        .force = 1,                // 强制播放（打断当前）
        .sample_rate = 16000,      // 16kHz
        .channels = 1,             // 单声道
        .bit_width = 16            // 16 位
    };

    int result = ai_audio_play(client, &params);
    if (result != AI_AUDIO_SUCCESS) {
        printf("播放失败: %s\n", ai_audio_get_error_string(result));
    }

    ai_audio_cleanup(client);
    return 0;
}
```

#### TTS 文本转语音

```c
#include "ai_audio.h"

int main() {
    ai_audio_t *client = ai_audio_init(NULL);

    // 简单 TTS
    ai_audio_play_tts_simple(client, "你好，欢迎使用AI语音助手");

    // 带参数 TTS
    ai_audio_tts_params_t tts_params = {
        .text = "这是一条重要通知",
        .volume = 90,
        .force = 0,          // 排队播放
        .use_cache = 1       // 使用缓存（相同文本复用）
    };
    ai_audio_play_tts(client, &tts_params);

    // 动态内容（禁用缓存）
    ai_audio_tts_params_t dynamic_params = {
        .text = "当前时间：下午三点整",
        .volume = 80,
        .force = 0,
        .use_cache = 0       // 动态内容不缓存
    };
    ai_audio_play_tts(client, &dynamic_params);

    ai_audio_cleanup(client);
    return 0;
}
```

#### 停止播放

```c
// 停止当前播放并清空队列
ai_audio_stop(client);
```

### 2.6 TTS 工作流程

```
1. 客户端发送 TTS 命令 → Unix Socket
2. ai-core 计算文本 MD5 → 检查缓存
3. 缓存命中 → 直接播放缓存的 PCM
4. 缓存未命中 → 调用云端 TTS API → 生成 PCM → 缓存 → 播放
```

- **缓存目录**：`/oem/usr/bin/resources/cache`
- **缓存策略**：基于文本 MD5，相同文本复用已生成的 PCM 文件

### 2.7 命令行工具

SDK 还提供了 `audio_play_client` 命令行工具：

```bash
# PCM 文件播放
./audio_play_client -f /path/to/audio.pcm -v 80

# TTS 文本播放
./audio_play_client -t "你好世界" -v 90

# 强制播放（打断当前）
./audio_play_client -f /tmp/urgent.pcm -F

# 停止播放
./audio_play_client -S
```

    --device_rate=16000 \
    --input_rate=22000 \

## 4. 方式三：ALSA 直接播放

### 4.1 基本播放代码

```c
#include <alsa/asoundlib.h>

#define SAMPLE_RATE  16000
#define CHANNELS     2
#define FORMAT       SND_PCM_FORMAT_S16_LE

int play_pcm(const char *device, const uint8_t *pcm_data, size_t data_len) {
    snd_pcm_t *handle;
    snd_pcm_hw_params_t *hw_params;

    // 打开播放设备
    snd_pcm_open(&handle, device, SND_PCM_STREAM_PLAYBACK, 0);

    // 设置参数
    snd_pcm_hw_params_malloc(&hw_params);
    snd_pcm_hw_params_any(handle, hw_params);
    snd_pcm_hw_params_set_access(handle, hw_params,
                                  SND_PCM_ACCESS_RW_INTERLEAVED);
    snd_pcm_hw_params_set_format(handle, hw_params, FORMAT);
    snd_pcm_hw_params_set_channels(handle, hw_params, CHANNELS);

    unsigned int rate = SAMPLE_RATE;
    snd_pcm_hw_params_set_rate_near(handle, hw_params, &rate, 0);

    snd_pcm_uframes_t period = 1024;
    snd_pcm_hw_params_set_period_size_near(handle, hw_params, &period, 0);

    snd_pcm_hw_params(handle, hw_params);
    snd_pcm_hw_params_free(hw_params);

    // 写入 PCM 数据
    int frame_size = CHANNELS * 2;  // 16bit * 2ch = 4 bytes/frame
    size_t offset = 0;
    while (offset < data_len) {
        int frames = (data_len - offset) / frame_size;
        if (frames > period) frames = period;

        int written = snd_pcm_writei(handle, pcm_data + offset, frames);
        if (written < 0) {
            written = snd_pcm_recover(handle, written, 0);
        }
        if (written > 0) {
            offset += written * frame_size;
        }
    }

    snd_pcm_drain(handle);
    snd_pcm_close(handle);
    return 0;
}
```

## 5. 方式四：Rockchip MPI ADEC→AO 管线

适用于需要解码编码音频后播放的场景：

```c
// samples/live_broadcast/simple_adec_bind_ao.c

// 配置 AO 属性
AO_CHN_ATTR_S aoAttr;
sprintf(aoAttr.u8CardName, "hw:0,0");
aoAttr.soundCard.channels = 2;
aoAttr.soundCard.sampleRate = 48000;
aoAttr.soundCard.bitWidth = AUDIO_BIT_WIDTH_16;
aoAttr.enBitwidth = AUDIO_BIT_WIDTH_16;
aoAttr.enSamplerate = (AUDIO_SAMPLE_RATE_E)16000;

// 创建 AO 通道
RK_MPI_AO_SetChnAttr(0, 0, &aoAttr);
RK_MPI_AO_EnableChn(0, 0);

// 设置音量
RK_MPI_AO_SetVolume(0, volume);

// 绑定 ADEC → AO
RK_MPI_SYS_Bind(&adec_src, &ao_dst);

// 设置扬声器输出路径（仅 RV1126/RV1109）
#if defined(RV1126_RV1109)
RK_MPI_AMIX_SetControl(0, "Playback Path", "SPK");
#endif
```

## 6. 音频文件要求

| 参数 | 范围 | 推荐值 |
|------|------|--------|
| 格式 | PCM (Raw) | 无压缩 |
| 采样率 | 8000 ~ 96000 Hz | 16000 Hz |
| 声道数 | 1 ~ 8 | 2 (双声道) |
| 位宽 | 8 / 16 / 24 / 32 bit | 16 bit |

> **注意**：SDK API 仅支持裸 PCM 格式。播放 WAV/MP3 等编码格式需先解码为 PCM，或使用 `rk_mpi_ao_test` 工具（支持 WAV）。

## 8. 注意事项

1. **ai-core 先启动**：使用 SDK API 前确保 `ai-core` 服务已运行
2. **排队 vs 打断**：`force=0` 排队播放，`force=1` 立即打断当前并播放新内容
3. **stop 清空队列**：`ai_audio_stop()` 会同时停止播放和清空队列
4. **cleanup 不影响服务端**：`ai_audio_cleanup()` 仅释放客户端资源，不停止服务端播放
5. **TTS 网络依赖**：TTS 功能需要网络连接（云端 TTS API），离线环境仅能播放已缓存的文本
6. **音量范围**：0（静音）~ 100（最大），-1 使用服务端默认值
