# 麦克风接口文档

> **适用平台**: OSAIG 开源 AI 眼镜 (RV1106B)
> **音频子系统**: ALSA / Rockchip MPI (AI 模块)
> **硬件**: 板载 MEMS 麦克风

---

## 1. 概述

眼镜端的麦克风采集功能主要由 `ai-core` 服务内部管理。当前开源仓库中**未包含完整的设备端麦克风采集源码**，但提供了以下参考实现：

- PC 端 PyAudio 录音 + TCP 传输示例
- Rockchip MPI 音频输入 (AI) 模块头文件引用
- `ai-core` 服务端集中管理麦克风的架构描述

**关键文件：**

| 文件 | 作用 |
|------|------|
| `samples/audio_streaming/audio_client.py` | PC 端麦克风采集 + TCP 发送示例 |
| `samples/audio_streaming/audio_server.c` | 设备端接收 PCM 并 ALSA 播放 |
| `samples/live_broadcast/simple_vi_bind_venc.c` | 包含 `rk_mpi_ai.h` 引用（未实际使用 AI 模块） |
| `samples/live_broadcast/Readme.txt` | 提到 `rk_mpi_ai_test` 工具 |

## 2. 音频采集架构

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│   MEMS 麦克风  │───►│   ALSA/MPI   │───►│   ai-core    │
│   (硬件)      │    │  音频输入驱动  │    │  (服务端)    │
└──────────────┘    └──────────────┘    └──────┬───────┘
                                               │
                                    ┌──────────┼──────────┐
                                    │          │          │
                                    ▼          ▼          ▼
                              AI 语音识别   音频流转发   录音存储
```

> **说明**：`ai-core` 是闭源服务端二进制，负责统一管理摄像头、麦克风和喇叭。设备端麦克风采集的具体实现在 `ai-core` 内部完成，当前开源仓库未包含该部分源码。

## 3. 音频采集参数

### 3.1 标准参数（基于示例代码推断）

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 采样率 | 16000 Hz | 适用于语音识别和通话 |
| 声道数 | 2（双声道） | 与设备硬件匹配 |
| 位深 | 16 bit (S16_LE) | 有符号 16 位小端 |
| 帧大小 | 1024 帧/块 | PyAudio chunk 参数 |

### 3.2 声卡设备

| 设备标识 | 类型 | 说明 |
|----------|------|------|
| `default` | ALSA | 默认音频设备 |
| `hw:0,0` | ALSA | 硬件声卡 0，设备 0 |

## 4. 方式一：PyAudio 录音 + TCP 传输（PC 端示例）

此示例演示了从 PC 麦克风采集音频并通过 TCP 发送到眼镜端播放的完整流程。

### 4.1 客户端代码（PC 端采集）

```python
# samples/audio_streaming/audio_client.py
import pyaudio
import socket

class AudioClient:
    def __init__(self, server_ip, server_port=8888):
        self.server_ip = server_ip
        self.server_port = server_port

        # 音频参数
        self.format = pyaudio.paInt16
        self.channels = 2          # 双声道
        self.rate = 16000           # 16kHz 采样率
        self.chunk = 1024           # 每次读取帧数

    def start(self):
        self.audio = pyaudio.PyAudio()
        self.stream = self.audio.open(
            format=self.format,
            channels=self.channels,
            rate=self.rate,
            input=True,
            frames_per_buffer=self.chunk
        )

        self.sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        self.sock.connect((self.server_ip, self.server_port))

        while True:
            data = self.stream.read(self.chunk)
            self.sock.sendall(data)
```

### 4.2 服务端代码（设备端接收播放）


## 5. 方式二：ALSA 直接采集（需自行实现）

若需在设备端直接从麦克风采集音频，可参考以下 ALSA 采集代码框架：

```c
#include <alsa/asoundlib.h>

#define SAMPLE_RATE  16000
#define CHANNELS     2
#define PERIOD_SIZE  1024

int capture_audio(const char *output_file) {
    snd_pcm_t *handle;
    snd_pcm_hw_params_t *params;
    int16_t *buffer;
    int frames;

    // 打开 CAPTURE 设备
    snd_pcm_open(&handle, "hw:0,0", SND_PCM_STREAM_CAPTURE, 0);

    // 设置硬件参数
    snd_pcm_hw_params_malloc(&params);
    snd_pcm_hw_params_any(handle, params);
    snd_pcm_hw_params_set_access(handle, params,
                                  SND_PCM_ACCESS_RW_INTERLEAVED);
    snd_pcm_hw_params_set_format(handle, params, SND_PCM_FORMAT_S16_LE);
    snd_pcm_hw_params_set_channels(handle, params, CHANNELS);

    unsigned int rate = SAMPLE_RATE;
    snd_pcm_hw_params_set_rate_near(handle, params, &rate, 0);

    snd_pcm_uframes_t period = PERIOD_SIZE;
    snd_pcm_hw_params_set_period_size_near(handle, params, &period, 0);

    snd_pcm_hw_params(handle, params);

    // 分配缓冲区
    int buffer_size = PERIOD_SIZE * CHANNELS * sizeof(int16_t);
    buffer = (int16_t *)malloc(buffer_size);

    // 采集循环
    FILE *fp = fopen(output_file, "wb");
    while (recording) {
        frames = snd_pcm_readi(handle, buffer, PERIOD_SIZE);
        if (frames < 0) {
            frames = snd_pcm_recover(handle, frames, 0);
        }
        if (frames > 0) {
            fwrite(buffer, sizeof(int16_t) * CHANNELS, frames, fp);
        }
    }

    fclose(fp);
    free(buffer);
    snd_pcm_close(handle);
    return 0;
}
```

## 6. 方式三：Rockchip MPI AI 模块（录音/推流场景）

RV1106B 平台提供了 Rockchip Media Process Interface (MPI) 的音频输入 (AI) 模块，适用于对接硬件编解码器的场景。

### 6.1 `rk_mpi_ai_test` 工具

固件中自带的测试工具，可直接从命令行采集音频：

```bash
# 从声卡 hw:0,0 采集，16kHz，双声道，16bit
rk_mpi_ai_test \
    --sound_card_name=hw:0,0 \
    --device_ch=2 \
    --device_rate=16000 \
    -o /tmp/recorded.pcm
```

### 6.2 MPI AI 模块 API（需链接 rockit 库）

```c
#include "rk_mpi_ai.h"

// 基本使用流程
RK_MPI_SYS_Init();

// 配置 AI 通道属性
AI_CHN_ATTR_S aiAttr;
sprintf(aiAttr.u8CardName, "hw:0,0");
aiAttr.soundCard.channels = 2;
aiAttr.soundCard.sampleRate = 16000;
aiAttr.soundCard.bitWidth = AUDIO_BIT_WIDTH_16;

// 启用 AI 通道
RK_MPI_AI_SetChnAttr(0, 0, &aiAttr);
RK_MPI_AI_EnableChn(0, 0);

// 获取音频帧
AUDIO_FRAME_S frame;
RK_MPI_AI_GetFrame(0, 0, &frame, 1000);
// ... 处理 frame.pVirAddr 中的 PCM 数据 ...
RK_MPI_AI_ReleaseFrame(0, 0, &frame);

// 清理
RK_MPI_AI_DisableChn(0, 0);
RK_MPI_SYS_Exit();
```

> **注意**：MPI AI 模块的完整实现需要链接 Rockchip `rockit` 库，该库在系统 SDK 中而非当前开源仓库中。

## 7. ai-core 集成路径（推荐）

在实际产品中，麦克风采集由 `ai-core` 统一管理。应用通过启动 `ai-core` 并配置参数来使用麦克风：

```bash
# 启动 ai-core 并启用麦克风/AI 功能
./ai-core --enable-camera --enable-gpio
```

应用程序可通过以下方式间接使用麦克风：
- **AI 语音对话**：`ai-core` 内部采集音频并发送到云端 ASR
- **按键触发录音**：通过 GPIO 按键触发录音流程（参见按键文档）

## 9. 注意事项

1. **ai-core 优先**：生产环境建议通过 `ai-core` 服务管理麦克风，避免多进程抢占设备
2. **声卡设备**：默认声卡为 `hw:0,0`，具体设备号根据固件版本可能不同
3. **采样率匹配**：确保采集端和处理端使用一致的采样率（推荐 16kHz）
4. **权限**：访问 ALSA 设备可能需要 root 权限或适当的用户组
5. **功耗**：持续录音会增加功耗，建议按需开启
