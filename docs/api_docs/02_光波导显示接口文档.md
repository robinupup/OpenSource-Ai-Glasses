# 光波导显示接口文档

> **适用平台**: OSAIG 开源 AI 眼镜 (RV1106B)
> **显示面板**: JBD013 Micro-OLED
> **通信接口**: SPI (`/dev/spidev0.0`)
> **分辨率**: 640×480，4bpp (每像素4位灰度)

---

## 1. 概述

眼镜采用 JBD013 Micro-OLED 微显示模组，通过 SPI 接口驱动，光学上经光波导（Waveguide）投射至用户视野。显示系统采用**客户端渲染 + 服务端推屏**的架构：

- **客户端 (App)**：使用 LVGL 进行 UI 渲染，将像素数据写入共享内存
- **服务端 (display-service)**：监听共享内存，将帧数据通过 SPI 推送到 JBD013 面板

**关键文件：**

| 文件 | 作用 |
|------|------|
| `SDK/ai_glass_sdk/include/ai_display.h` | 显示客户端 API 头文件 |
| `SDK/ai_glass_sdk/docs/Display_Client_API.md` | API 文档 |
| `src/display-service/main.c` | 显示服务守护进程 |
| `src/display-service/hal_driver.c` | SPI HAL 驱动层 |
| `src/display-service/jbd013_api.c` | JBD013 面板控制 API |
| `src/launcher-app/main.c` | Launcher 应用（LVGL + ai_display） |
| `docs/DISPLAY_SERVICE_DESIGN.md` | 显示服务架构设计文档 |

## 2. 架构设计

```
┌─────────────────────┐       ┌──────────────────────────┐
│   Client App        │       │   ai_display_service     │
│                     │       │                          │
│  ┌───────────────┐  │       │  ┌────────────────────┐  │
│  │ LVGL 渲染引擎  │  │       │  │  接收 commit 消息   │  │
│  └───────┬───────┘  │       │  └─────────┬──────────┘  │
│          │ flush_cb  │       │            │             │
│          ▼          │       │            ▼             │
│  ┌───────────────┐  │  SHM  │  ┌────────────────────┐  │
│  │  帧缓冲写入    │◄─┼──────┼─►│  读取帧缓冲         │  │
│  └───────────────┘  │       │  └─────────┬──────────┘  │
│          │          │       │            │             │
│          ▼          │  UDS  │            ▼             │
│  ┌───────────────┐  │       │  ┌────────────────────┐  │
│  │ commit_frame  │──┼──────┼─►│  SPI 推送到面板      │  │
│  └───────────────┘  │       │  └────────────────────┘  │
└─────────────────────┘       └──────────────────────────┘
```

- **SHM**: POSIX 共享内存 `/ai_display_shm` (512KB)
- **UDS**: Unix Domain Socket 命令通道

## 4. 客户端 API

### 4.1 API 一览

| 函数 | 描述 |
|------|------|
| `ai_display_init()` | 初始化客户端，返回句柄 |
| `ai_display_connect(client)` | 连接到显示服务 |
| `ai_display_disconnect(client)` | 断开连接（可重连） |
| `ai_display_get_framebuffer(client)` | 获取主帧缓冲指针 (Slot 0) |
| `ai_display_get_framebuffer_slot(client, slot)` | 获取指定槽位的帧缓冲指针 |
| `ai_display_commit_frame(client, slot, x, y, w, h)` | 提交帧更新到屏幕 |
| `ai_display_request_focus(client)` | 请求显示焦点（多客户端场景） |
| `ai_display_set_power_save_timeout(client, sec)` | 设置息屏超时（0=禁用） |
| `ai_display_cleanup(client)` | 清理资源 |
| `ai_display_is_connected(client)` | 检查连接状态 |
| `ai_display_get_error_string(code)` | 错误码转字符串 |

### 4.2 错误码

| 错误码 | 值 | 说明 |
|--------|-----|------|
| `AI_DISPLAY_SUCCESS` | 0 | 成功 |
| `AI_DISPLAY_ERROR_INIT` | -1 | 初始化失败 |
| `AI_DISPLAY_ERROR_CONNECT` | -2 | 连接失败 |
| `AI_DISPLAY_ERROR_SHM` | -3 | 共享内存操作失败 |
| `AI_DISPLAY_ERROR_SOCKET` | -4 | Socket 操作失败 |

### 4.3 共享内存布局

```c
typedef struct {
    uint32_t magic;                  // 0x44495350 = "DISP"
    volatile int active_client_pid;  // 当前前台显示的进程 PID

    // Slot 0: 主应用全屏渲染 (153600 bytes)
    uint8_t framebuffer_slot_0[AI_DISPLAY_FRAME_SIZE];
    // Slot 1: overlay 叠加层/通知 (153600 bytes)
    uint8_t framebuffer_slot_1[AI_DISPLAY_FRAME_SIZE];
} ai_display_shm_t;
```

## 5. 使用示例

### 5.1 最简示例：填充黑色全屏

```c
#include "ai_display.h"
#include <string.h>

int main() {
    // 1. 初始化客户端
    ai_display_client_t *client = ai_display_init();
    if (!client) return -1;

    // 2. 连接到显示服务
    if (ai_display_connect(client) != AI_DISPLAY_SUCCESS) {
        ai_display_cleanup(client);
        return -1;
    }

    // 3. 获取帧缓冲指针
    uint8_t *fb = ai_display_get_framebuffer(client);
    if (!fb) {
        ai_display_cleanup(client);
        return -1;
    }

    // 4. 写入帧数据（全黑）
    memset(fb, 0x00, AI_DISPLAY_FRAME_SIZE);

    // 5. 提交帧到屏幕
    ai_display_commit_frame(client, 0, 0, 0, AI_DISPLAY_WIDTH, AI_DISPLAY_HEIGHT);

    // 6. 清理
    ai_display_cleanup(client);
    return 0;
}
```

### 5.2 使用 Overlay 槽位

```c
// 获取 overlay 帧缓冲 (Slot 1)
uint8_t *overlay = ai_display_get_framebuffer_slot(client, 1);
if (overlay) {
    // 绘制 overlay 内容...
    ai_display_commit_frame(client, 1, 0, 0, AI_DISPLAY_WIDTH, AI_DISPLAY_HEIGHT);
}
```

### 5.3 息屏控制

```c
// 设置 10 秒后自动息屏
ai_display_set_power_save_timeout(client, 10);

// 禁用自动息屏
ai_display_set_power_save_timeout(client, 0);
```

## 6. 像素格式与帧缓冲操作

### 6.1 4bpp 打包格式

每个字节存储 2 个像素（每像素 4 位灰度，0x0~0xF）：

```
字节:  [高4位 | 低4位]
像素:  [像素1  | 像素2 ]
```

- 高 4 位 = 左像素（偶数列）
- 低 4 位 = 右像素（奇数列）
- 灰度值范围：0x0（黑）~ 0xF（白）
- 一行 640 像素 = 320 字节

### 6.2 手动填充帧缓冲

```c
// 在 (x, y) 处设置一个像素的灰度值
void set_pixel(uint8_t *fb, int x, int y, uint8_t gray4bit) {
    int byte_offset = y * 320 + x / 2;
    if (x % 2 == 0) {
        fb[byte_offset] = (gray4bit << 4) | (fb[byte_offset] & 0x0F);
    } else {
        fb[byte_offset] = (fb[byte_offset] & 0xF0) | (gray4bit & 0x0F);
    }
}
```

## 7. 使用 LVGL 进行 UI 渲染（推荐）

Launcher 应用演示了如何将 LVGL 与 `ai_display` 结合使用。

### 7.1 LVGL 配置

- **颜色深度**：8bpp（`lv_conf.h` 中配置 `LV_COLOR_DEPTH 8`）
- **输出转换**：在 `flush_cb` 中将 LVGL 的 8bpp 像素压缩为 4bpp 写入共享内存

### 7.2 Flush 回调实现

```c
// src/launcher-app/main.c
static void disp_flush(lv_disp_drv_t *disp_drv, const lv_area_t *area,
                       lv_color_t *color_p)
{
    int w = area->x2 - area->x1 + 1;
    int h = area->y2 - area->y1 + 1;
    uint8_t *shm_buf = ai_display_get_framebuffer(disp_client);

    for (int y = 0; y < h; y++) {
        int shm_y = area->y1 + y;
        uint8_t *dst = shm_buf + (shm_y * 320) + (area->x1 / 2);
        const lv_color_t *src = color_p + (y * w);

        for (int i = 0; i < w; i += 2) {
            uint8_t p1 = (src[i].full & 0xF0);           // 高4位
            uint8_t p2 = (i + 1 < w) ?
                         ((src[i+1].full & 0xF0) >> 4) : 0; // 低4位
            dst[i / 2] = p1 | p2;
        }
    }

    if (lv_disp_flush_is_last(disp_drv)) {
        ai_display_commit_frame(disp_client, 0, 0, 0,
                                SCREEN_WIDTH, SCREEN_HEIGHT);
    }
    lv_disp_flush_ready(disp_drv);
}
```

### 7.3 LVGL 初始化

```c
int init_lvgl(void) {
    lv_init();
    static lv_disp_draw_buf_t draw_buf;
    static lv_color_t buf1[SCREEN_WIDTH * 10];
    lv_disp_draw_buf_init(&draw_buf, buf1, NULL, SCREEN_WIDTH * 10);

    static lv_disp_drv_t disp_drv;
    lv_disp_drv_init(&disp_drv);
    disp_drv.hor_res = SCREEN_WIDTH;   // 640
    disp_drv.ver_res = SCREEN_HEIGHT;  // 480
    disp_drv.flush_cb = disp_flush;
    disp_drv.draw_buf = &draw_buf;
    lv_disp_drv_register(&disp_drv);
    return 0;
}
```

以下为 `display-service` 内部使用的底层硬件 API：

                  uint8_t *pBuf, uint32_t len);  // 写显存

### 8.2 JBD013 面板 API

```c
// src/display-service/jbd013_api.c
void panel_init(void);               // 面板初始化（复位、设置电流、镜像模式等）

                   uint8_t *pBuf, uint32_t len);  // 显示图像

void wr_cur_reg(int value);          // 设置驱动电流

```

常用 SPI 命令字：

| 命令 | 值 | 说明 |
|------|-----|------|
| `SPI_DISPLAY_ENABLE` | 0xA3 | 开启显示 |
| `SPI_DISPLAY_DISABLE` | 0xA5 | 关闭显示 |
| `SPI_SYNC` | 0x97 | 同步缓存到屏幕 |
| `SPI_WR_ENABLE` | 0xA1 | 使能写入 |

## 10. 注意事项

1. **服务端先启动**：调用 `ai_display_connect()` 前，`display-service` 必须已运行
2. **线程安全**：单个客户端句柄不应在多线程中并发使用
3. **帧缓冲格式**：必须使用 4bpp 打包格式，大小恰好为 `AI_DISPLAY_FRAME_SIZE` 字节
4. **默认镜像**：面板初始化时默认启用镜像模式 `set_mirror_mode(1)`，适配光波导光路
5. **省电机制**：服务端支持超时自动息屏 (`SPI_DISPLAY_DISABLE`)，GPIO 按键或 commit 操作可唤醒
