# 相机接口文档

> **适用平台**: OSAIG 开源 AI 眼镜 (RV1106B)
> **传感器接口**: V4L2 (`/dev/video7`)，子设备 (`/dev/v4l-subdev2`)
> **最大分辨率**: 1920×1080
> **输出格式**: JPEG / NV12

---

## 1. 概述

眼镜端搭载摄像头模组，支持拍照和录像。项目提供了三种使用摄像头的方式：

1. **SDK 客户端 API**（推荐）：通过 `ai_camera.h` 对接 `ai-core` 服务，零拷贝获取图像
2. **V4L2 直接采集**：通过 Linux V4L2 接口直接操作 `/dev/video7`
3. **Rockchip MPI**：通过 VI→VENC 管线实现高效录像/推流

**关键文件：**

| 文件 | 作用 |
|------|------|
| `SDK/ai_glass_sdk/include/ai_camera.h` | 相机客户端 API 头文件 |
| `SDK/ai_glass_sdk/docs/Camera_Client_API.md` | API 文档 |
| `SDK/ai_glass_sdk/examples/camera_capture_example/` | SDK 示例 |
| `src/ffm_launcher/launch.cpp` | V4L2 采集 + ffmpeg 转 JPEG 实现 |
| `src/touchpad_manager/launch.cpp` | v4l2-ctl 命令行拍照 |
| `samples/live_broadcast/simple_vi_bind_venc.c` | MPI VI→VENC 示例 |

## 2. 方式一：SDK 客户端 API（推荐）

### 2.1 架构

```
┌──────────────┐    Unix Socket     ┌──────────────┐    V4L2/ISP    ┌────────┐
│   应用程序    │ ◄────────────────► │   ai-core    │ ◄────────────► │ Camera │
│              │    共享内存 (SHM)   │   服务端      │                │ 传感器  │
└──────────────┘                    └──────────────┘                └────────┘
```

- **IPC 通道**：Unix Socket (`/tmp/ai-core_camera_ctrl`) + 共享内存 (`/ai-core_shm`, 2MB+1KB)
- **零拷贝**：图像数据通过共享内存传递，避免数据复制

### 2.2 API 一览

| 函数 | 描述 |
|------|------|
| `ai_core_init()` | 初始化客户端，连接到 ai-core 服务 |
| `ai_core_capture(client, &data, timeout_ms)` | 捕获一帧图像 |
| `ai_core_free_data(&data)` | 释放图像数据内存 |
| `ai_core_cleanup(client)` | 清理客户端资源 |
| `ai_core_get_error_string(code)` | 错误码转字符串 |

### 2.3 数据结构

```c
// 图像数据结构
typedef struct {
    uint8_t *data;      // 图像数据指针
    size_t size;        // 数据大小（字节）
    int width;          // 图像宽度
    int height;         // 图像高度
    int format;         // 格式: AI_MEDIA_FORMAT_JPEG(0) / AI_MEDIA_FORMAT_NV12(1)
    int sequence;       // 帧序号
} ai_core_data_t;
```

### 2.4 错误码

| 错误码 | 值 | 说明 |
|--------|-----|------|
| `AI_MEDIA_SUCCESS` | 0 | 成功 |
| `AI_MEDIA_ERROR_INIT` | -1 | 初始化失败 |
| `AI_MEDIA_ERROR_TIMEOUT` | -2 | 超时 |
| `AI_MEDIA_ERROR_CAPTURE` | -3 | 捕获失败 |
| `AI_MEDIA_ERROR_MEMORY` | -4 | 内存错误 |

### 2.5 使用示例

```c
#include "ai_camera.h"
#include <stdio.h>

int main() {
    // 1. 初始化客户端
    ai_core_client_t *client = ai_core_init();
    if (!client) {
        printf("初始化失败，请确保 ai-core 已启动\n");
        return -1;
    }

    // 2. 捕获图像（5秒超时）
    ai_core_data_t data;
    int result = ai_core_capture(client, &data, 5000);

    if (result == AI_MEDIA_SUCCESS) {
        printf("捕获成功: %dx%d, %zu bytes, 格式: %s\n",
               data.width, data.height, data.size,
               data.format == AI_MEDIA_FORMAT_JPEG ? "JPEG" : "NV12");

        // 3. 保存到文件
        const char *ext = (data.format == AI_MEDIA_FORMAT_JPEG) ? "jpg" : "nv12";
        char filename[128];
        snprintf(filename, sizeof(filename), "/tmp/capture.%s", ext);
        FILE *fp = fopen(filename, "wb");
        if (fp) {
            fwrite(data.data, 1, data.size, fp);
            fclose(fp);
            printf("已保存到 %s\n", filename);
        }

        // 4. 释放内存（必须调用！）
        ai_core_free_data(&data);
    } else {
        printf("捕获失败: %s\n", ai_core_get_error_string(result));
    }

    // 5. 清理
    ai_core_cleanup(client);
    return 0;
}
```

### 2.6 服务端启动参数

```bash
# 最小配置
./ai-core --enable-camera

# 推荐配置（JPEG 编码 + 3A 自动调节）
./ai-core --enable-camera --enable-jpeg --enable-3a
```

| 指标 | 值 |

| 并发支持 | 多客户端同时捕获 |

## 3. 方式二：V4L2 直接采集

### 3.1 设备节点

| 设备 | 用途 |
|------|------|
| `/dev/video7` | 视频采集主设备 |
| `/dev/v4l-subdev2` | 子设备（曝光/增益控制） |

### 3.2 采集流程（ffm_launcher 实现）

```c
// src/ffm_launcher/launch.cpp
#define DEVICE "/dev/video7"
#define WIDTH  1920
#define HEIGHT 1080

int capture_nv12_frame(const char *output_file) {
    int fd = open(DEVICE, O_RDWR);

    // 设置格式
    struct v4l2_format fmt = {0};
    fmt.type = V4L2_BUF_TYPE_VIDEO_CAPTURE_MPLANE;
    fmt.fmt.pix_mp.width = WIDTH;
    fmt.fmt.pix_mp.height = HEIGHT;
    fmt.fmt.pix_mp.pixelformat = V4L2_PIX_FMT_NV12;
    ioctl(fd, VIDIOC_S_FMT, &fmt);

    // 申请缓冲区
    struct v4l2_requestbuffers req = {0};
    req.count = 1;
    req.type = V4L2_BUF_TYPE_VIDEO_CAPTURE_MPLANE;
    req.memory = V4L2_MEMORY_MMAP;
    ioctl(fd, VIDIOC_REQBUFS, &req);

    // mmap 映射
    struct v4l2_buffer buf = {0};
    buf.type = V4L2_BUF_TYPE_VIDEO_CAPTURE_MPLANE;
    buf.memory = V4L2_MEMORY_MMAP;
    buf.index = 0;
    // ... mmap + QBUF + STREAMON + DQBUF ...

    // 保存 NV12 原始数据
    FILE *fp = fopen(output_file, "wb");
    fwrite(mapped_buffer, 1, frame_size, fp);
    fclose(fp);

    close(fd);
    return 0;
}
```

### 3.3 曝光和增益控制

```c
// 设置子设备参数
void set_camera_controls() {
    int subdev_fd = open("/dev/v4l-subdev2", O_RDWR);

    // 设置曝光
    struct v4l2_control ctrl;
    ctrl.id = V4L2_CID_EXPOSURE;
    ctrl.value = 1300;
    ioctl(subdev_fd, VIDIOC_S_CTRL, &ctrl);

    // 设置模拟增益
    ctrl.id = V4L2_CID_ANALOGUE_GAIN;
    ctrl.value = 500;
    ioctl(subdev_fd, VIDIOC_S_CTRL, &ctrl);

    close(subdev_fd);
}
```

### 3.4 NV12 转 JPEG

采集的 NV12 原始数据通过 ffmpeg 转换为 JPEG：

```bash
ffmpeg -y \
    -f rawvideo -pixel_format nv12 -s 1920x1080 \
    -i /opt/frame_nv12.raw \
    -vf scale=512:288 \
    -q:v 5 \
    -f image2 /opt/frame.jpg
```

### 3.5 完整拍照流程（ffm_launcher）

```
1. set_camera_controls()          → 设置曝光/增益
2. capture_nv12_frame()           → 采集 1920x1080 NV12
3. ffmpeg 转 JPEG                 → 缩放为 512x288 JPEG
4. cp /opt/frame.jpg /tmp/123.jpg → 复制到临时目录
5. touch /tmp/send                → 触发 BLE 图片推送
6. send_to_display("PhotoCaptured") → 通知显示端
```

## 4. 方式三：v4l2-ctl 命令行拍照

```bash
# 设置曝光和增益
v4l2-ctl -d /dev/v4l-subdev2 --set-ctrl=exposure=1300,analogue_gain=500

# 采集一帧 NV12
v4l2-ctl -d /dev/video7 \
    --set-fmt-video=width=1920,height=1080,pixelformat=NV12 \
    --stream-mmap=3 \
    --stream-to=/tmp/1.raw \
    --stream-count=1 \
    --stream-skip=1

# 转换为 JPEG（缩放到 512x288）
ffmpeg -y \
    -f rawvideo -pixel_format nv12 -s 1920x1080 \
    -i /tmp/1.raw \
    -vf scale=512:288 \
    -q:v 5 -frames:v 1 \
    -f image2 /tmp/123.jpg

# 归档
mkdir -p /userdata/Rec
cp /tmp/123.jpg /userdata/Rec/P$(date +%s).jpg
```

## 5. 方式四：Rockchip MPI 录像/推流

### 5.1 VI→VENC 管线

适用于高效录像和 RTMP/RTSP 推流场景：

```c
// samples/live_broadcast/simple_vi_bind_venc.c
RK_U32 u32Width = 1920;
RK_U32 u32Height = 1080;

RK_MPI_SYS_Init();

// 配置 VI 通道
VI_CHN_ATTR_S vi_chn_attr;
vi_chn_attr.stSize.u32Width = u32Width;
vi_chn_attr.stSize.u32Height = u32Height;
vi_chn_attr.enPixelFormat = RK_FMT_YUV420SP;  // NV12
vi_chn_attr.stIspOpt.enMemoryType = VI_V4L2_MEMORY_TYPE_DMABUF;

RK_MPI_VI_SetChnAttr(0, 0, &vi_chn_attr);
RK_MPI_VI_EnableChn(0, 0);

// 配置 VENC 通道
VENC_CHN_ATTR_S venc_chn_attr;
// ... 设置编码类型 (H.264/H.265/MJPEG) ...

RK_MPI_VENC_CreateChn(0, &venc_chn_attr);

// 绑定 VI → VENC
RK_MPI_SYS_Bind(&vi_src, &venc_dst);

// 获取码流
VENC_STREAM_S stream;
RK_MPI_VENC_GetStream(0, &stream, 1000);
// ... 写文件或推流 ...
RK_MPI_VENC_ReleaseStream(0, &stream);
```

### 5.2 录像命令

```bash
# 录制 150 帧 H.264 视频
simple_vi_bind_venc -c 150 -o /userdata/Rec/out_$(date +%s).h264

# RTMP 推流（需配合 ffmpeg）
simple_vi_bind_venc -e h264 -w 1920 -h 1080 | \
    ffmpeg -i pipe:0 -f flv rtmp://server/live/stream
```

## 7. 注意事项

1. **ai-core 先启动**：使用 SDK API 前确保 `ai-core --enable-camera` 已运行
2. **设备独占**：V4L2 设备同一时间只能被一个进程打开，使用 SDK 方式可避免冲突
3. **内存释放**：使用 `ai_core_capture()` 后必须调用 `ai_core_free_data()` 释放
4. **图像格式**：启动 ai-core 时带 `--enable-jpeg` 可获取 JPEG 格式，否则为 NV12
5. **缩放**：ffm_launcher 和 touchpad_manager 都将 1080p 图像缩放到 512×288 以节省存储和传输
6. **归档路径**：拍照文件存储在 `/userdata/Rec/` 目录，命名格式 `P<timestamp>.jpg`
